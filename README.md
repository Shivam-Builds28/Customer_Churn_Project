# Customer Churn Prediction

## Overview
This project aims to build a predictive machine learning model to identify customers who are likely to churn. By analyzing historical customer data, the model helps businesses proactively apply retention strategies and reduce customer attrition.

## Dataset
The dataset contains customer demographics, account details, and service usage metrics. 
* **Link to Dataset:** [Telco Customer Churn Dataset (Kaggle)](https://www.kaggle.com/datasets/blastchar/telco-customer-churn) *(Note: Update this link with the exact dataset URL if different)*

## Technologies Used
* **Programming Language:** Python
* **Environment:** Jupyter Notebook
* **Data Manipulation:** Pandas, NumPy
* **Data Visualization:** Matplotlib, Seaborn
* **Machine Learning:** Scikit-Learn

## Setup and Run Instructions

1. **Ensure Python is installed** on your system (Python 3.8+ recommended).
2. **Navigate to the project directory** where the files are saved.
3. **Install the necessary dependencies** using the provided `requirements.txt` file:
   ```bash
   pip install -r requirements.txt
   ```
4. **Launch Jupyter Notebook:**
   ```bash
   jupyter notebook
   ```
5. **Open the project file:** `Shivam Kumar_Customer_Churn_Prediction.ipynb`.
6. **Run the notebook cells** sequentially to load the data, train the model, and view the evaluation metrics.

## Key Information
* **Model Used:** Random Forest Classifier.
* **Evaluation Metrics:** Accuracy, Precision, Recall, and F1-Score. Focus is given to balancing Precision and Recall to minimize false positives while effectively capturing true churners.
